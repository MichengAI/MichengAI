## 👋 关于我

我是迷城，一名 AI 工具开发者与内容创作者。

我关注的不是把 AI 说得更复杂，而是把它变成普通人和团队真正能用的工具、工作流与教程。这里主要记录我的开源项目、AI 实践和正在搭建的 DeepSeek Harness 生态。

- 🧩 开发实用的 AI 桌面工具与插件
- 🛠️ 把重复工作整理成可复用的 Skills 与自动化流程
- 📖 分享基础入门、场景实操和真实避坑经验
- 🔍 重视真实交付，不用演示效果代替可用结果

## 🧭 我正在做什么

```text
发现真实问题 → 做成可用工具 → 记录完整过程 → 分享可复用方法
```

当前主要方向：

- **AI 工具产品化**：让 Agent 与自动化能力真正进入日常工作
- **DeepSeek Harness 生态**：桌面端、插件、Skills、Agents 与连接能力
